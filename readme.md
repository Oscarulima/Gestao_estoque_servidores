

##  Manual do Usuário

### 1. Cadastro de Servidores e Peças
1. Acesse a aba **Cadastrar / Editar**.
2. Preencha as **Informações do Servidor**:
   - **Serial Number / Service Tag** *(Obrigatório - Campo Único)*.
   - **Marca** *(Ao selecionar Lenovo, Dell ou HPE, o sistema sugere o módulo de gerenciamento automaticamente)*.
   - **Modelo**, **Fator de Forma (SFF/LFF)**, **Qtd de Baias** e **Tipo de Backplane**.
   - Indique se possui **Trilho Deslizável** e **Bezel (Tampa Frontal)**.
3. Preencha a lista de **Peças e Componentes Internos**:
   - O sistema pré-carrega automaticamente as 11 peças padrão que acompanham o chassi (Placa Mãe, Fontes, Fans, Risers, Controladora RAID, Backplane, etc.).
   - Navegue rapidamente entre os campos usando apenas a tecla **`TAB`**.
   - Insira a **Quantidade (Qtd)**, o **Part Number (PN)** e a **Descrição/Detalhes** da peça.
   - *Nota: Processadores e Memórias não são cadastrados nesta etapa (ficam no estoque separado).*
   - Caso precise registrar um item extra, clique em **`+ Adicionar Peça Extra`**.
4. Clique no botão **Salvar Servidor**.

---

### 2. Consulta e Visualização de Detalhes
1. Acesse a aba **Consultar / Filtrar**.
2. Utilize o filtro **Filtrar por Marca** para limitar a exibição dos servidores.
3. Para ver a ficha técnica completa:
   - **Opção 1:** Dê um **duplo clique** sobre a linha do servidor na tabela.
   - **Opção 2:** Selecione o servidor e clique em **`👁️ Visualizar Detalhes`**.
4. Na janela de detalhes, clique em **`📋 Copiar Tudo para Área de Transferência`** caso precise enviar a lista de peças por WhatsApp, e-mail ou documento.

---

### 3. Edição de Servidores
1. Na aba **Consultar / Filtrar**, selecione o servidor desejado.
2. Clique no botão **` Editar Servidor`**.
3. O sistema carregará todos os dados de volta para a tela de cadastro e alterará o botão para **Atualizar Servidor**.
4. Faça as alterações necessárias e clique em **Atualizar Servidor**.

---

### 4. Exportação de Relatórios em CSV (Excel)
1. Na aba de cadastro, clique no botão **Exportar CSV**.
2. Escolha o local no seu computador onde deseja salvar o arquivo.
3. O relatório será gerado em blocos formatados com **SN**, **Server** e a lista de peças com **PN**, **Descrição** e **QTD**.

---

## Dicas Rápidas
* **Navegação rápida:** Preencha os campos e use **`TAB`** para ir para o próximo campo e rolar a tela automaticamente.
* **Bloqueio de duplicidade:** O sistema impede o cadastro de dois servidores com o mesmo Serial Number/Tag.
* **Limpar formulário:** Clique em **Limpar Formulário** para resetar os campos antes de cadastrar uma nova máquina.
